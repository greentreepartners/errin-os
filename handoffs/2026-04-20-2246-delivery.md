## What this chat decided / shipped / changed

One fix commit landed on main:

- `2bc6226` — `fix(cards): dashed border + title-row status pill + drop decorative checkbox`. Four files: `src/lib/task-status.ts` (new), `src/app/admin/_components/AdminTaskCard.tsx`, `src/app/page.tsx`, `FUTURE.md` (new). Resolves Bugs 1–4 from Brief 2B-Fix-1.
  - **Bug 1 (dashed border on private cards):** moved `border-style` from a Tailwind utility swap (`border-solid`/`border-dashed`) to an inline `style={{ borderStyle: ... }}` attribute on the `<article>` of both admin and public cards. Root cause was that `border-dashed` wasn't winning a specificity fight against `border`'s implicit style in the Tailwind v4 pipeline; public view never exposed the bug because server-side visibility filtering means private cards never render there. Inline style bypasses the Tailwind pipeline entirely.
  - **Bug 2 + 3 (status pill indistinguishable / no affordance):** relocated the status pill from the right-hand badge stack (admin-only) to the title row on both views. New shared helper `statusPillClasses(status, { interactive })` in `src/lib/task-status.ts` returns per-status background + text + border colors for all six statuses, plus per-status hover states when `interactive: true`. Admin passes `interactive: true` (button, `cursor-pointer`, hover, cycles status); public passes `interactive: false` (span, no cursor, no hover, same base colors). Redundant decorative "in progress" spans on both views removed — the pill itself now carries that signal uniformly.
  - **Bug 4 (decorative checkbox):** deleted the `<input type="checkbox" disabled>` element from the title row on both views. Served no purpose. Card content now renders flush with the card's left padding.
